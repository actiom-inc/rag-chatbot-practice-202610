# 講師用：RAGチャットボット ハンズオン（60分）

## 先行講義との接続

先行講義『RAGの技術構造と実践的な設計・精度改善』の **第1章「基本技術」** の直後（先行講義のスライド16「ハンズオン（別枠）」）に実施します。終了後は先行講師が **第2章「精度向上」** から再開します。

先行講義では、RAGの構成、文書解析、チャンク化、Embedding、ベクトル・キーワード・ハイブリッド検索、メタデータ、回答プロンプトが説明済みです。**概念の再講義はしない**でください。学んだ構成を1つのアプリとして動かすことが主目的です。

ハンズオンの到達点は「文書を登録し、質問に対応する根拠を検索し、根拠に基づく回答と検索結果を確認する」です。最後に「必要な根拠が出ていない」「根拠はあるのに回答が違う」を観察し、次の精度向上の講義へ引き継ぎます。複雑な改善手法はここでは実装しません。

## 事前確認

- 受講者にはDocker Desktop（またはDocker Engine + Compose V2）、Git、APIキーを案内。**ホストPCへのPython・uvのインストールは不要**
- 受講者へ案内する操作は README に統一し、講師専用の手順は受講者用READMEに混ぜない
- 事前に README の手順で `docker compose build` と `docker compose run --rm app python scripts/preflight.py --download-model` を実行してもらう。初回ビルドとモデルダウンロードに時間がかかる場合がある
- 回答生成APIの従量課金と、AIコーディングツールの利用契約が別であることを案内。APIを使わない人は見学参加
- APIキーは回収しない。サンプルは架空資料のみ。機密文書を入力させない
- 講師用の別作業フォルダで完成版を復元し、OpenAI/AnthropicいずれかのAPI接続からRAG回答までリハーサル
- DockerはPC上で起動。ソースコードは `.:/app` にbind mountするため、ホストのAIコーディングツールで編集した変更はコンテナから読める
- Windows/macOS/LinuxでのDocker起動とファイル変更の反映を代表環境で確認する

## デモの質問と期待結果

`01_ai_training.txt` 登録後：

- 「研修の申込期限は？」→2026年11月30日17:00
- 「いつまでに申し込む？」→同じ締切が見つかるか
- 「来年度のAI研修予算は？」→資料に記載なし。ただしLLMの回答は保証されないため、出典と検索結果を必ず確認する

先行講義の例との接続用として `04_travel_policy.txt` も用意しています。余裕があれば登録し、「大阪出張で1泊13,000円のホテルは使える？」を試す。期待する根拠は第8条「上限12,000円」と第9条「部門長の事前承認と理由の記録」。**このTXTは先行講義の架空設定をもとに新たに作成した演習データ**です。

## トラブルシューティング

- Dockerが起動しない → Docker Desktopの起動、`docker compose ps`、`docker compose logs --tail=100 app` を確認
- 8501番が使われている → 競合するローカルアプリを停止（Composeの公開ポートは127.0.0.1:8501）
- 依存ライブラリが見つからない → `docker compose build` を再実行。ホストで `pip` や `uv` を実行しない
- Embeddingモデルの取得が遅い → `docker compose run --rm app python scripts/preflight.py --download-model` で事前取得
- APIエラー → `.env` のプロバイダー・キーの有無・モデルID・課金設定を確認（**秘密の値は見せてもらわない**）
- チャットが反応しない → コンテナログ、ブラウザの再読み込み、AIコーディングツールによる変更内容を確認
- 検索結果がない → ファイルがUTF-8か、登録件数が増えたか確認する
- 前のコードに戻したい → `docker compose run --rm --user 0:0 app python scripts/restore_checkpoint.py stepN`（変更前をバックアップする）
- DBは名前付きボリューム `rag_data` に保存される。**`docker compose down -v` はDBとモデルキャッシュの両方を消去するので通常の復旧には使わない**

## 任意のおまけ：グラフエンジニアリング（0〜15分）
